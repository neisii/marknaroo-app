# MarkNaroo

A lightweight Markdown viewer PWA.

**App:** https://neisii.github.io/marknaroo-app/

Install it from Chrome (install icon in the address bar, or the [Install] button on the empty screen), then open `.md` files with it via "Open with" / double-click from your OS file browser — the first time, Chrome shows a one-time confirmation dialog.

It works offline once installed. Local files are read on your device and are never uploaded anywhere.

This repository contains build output only; the source is private.

## MarkNaroo (한국어)

가벼운 마크다운 뷰어 PWA입니다.

**앱 주소:** https://neisii.github.io/marknaroo-app/

Chrome에서 설치할 수 있습니다(주소창의 설치 아이콘 또는 빈 화면의 [Install] 버튼). 설치 후에는 OS 파일 탐색기에서 `.md` 파일을 "연결 프로그램"으로 열거나 더블클릭으로 열 수 있습니다 — 처음 열 때는 Chrome이 한 번 확인 창을 띄웁니다.

설치하면 오프라인에서도 동작합니다. 로컬 파일은 기기 안에서만 읽으며 어디로도 업로드하지 않습니다.

이 저장소에는 빌드 산출물만 있으며, 소스는 비공개입니다.
